Now add a new format named "SRA Brief" (the corresponding cli value would be "sra-brief").

The contents of the table will be a subset of the landscape-detail format,
so you may reuse the same data-extraction logic.

It would be slightly similar to SA Brief, in terms of their level of detail.

This is a single table that contains the findings in the SRA sheet.
The table format is as follows:

| **#**   | **Findings**   | **Risk Level**   |
|:--------|:---------------|:-----------------|
| **General Control Review**                  |
| G1      | ...            | Medium           |
| G2      | ...            | Low              |
| G3      | ...            | Low              |
| **Vulnerability Scanning**                  |
| V1      | ...            | Critical         |
| V2      | ...            | High             |
| V3      | ...            | High             |
| V4      | ...            | High             |
| V5      | ...            | Low              |
| V6      | ...            | Low              |
| **Web Penetration Testing**                 |
| W1      | ...            | High             |
| W2      | ...            | High             |
| W3      | ...            | Medium           |
| W4      | ...            | Low              |
| **API Penetration Testing**                 |
| A1      | ...            | Medium           |
| A2      | ...            | Medium           |
| A3      | ...            | Low              |

Notice the cells which I've marked with double asterisks as bold.
Note that the section header cells should be filled with the "Blue, Accent 1, Lighter 80%" color from MS Word.
The risk level cells should be filled with the corresponding colors I've provided for landscape-detail and portrait detail.
Also note that the first row should not be color-filled. Keep the row un-filled instead of filling it blue.
